# Zrain v2.3.0 manual acceptance checklist

**Mobile first. No mandatory tutorials. No hidden auto-download.**

1. Crop Image: on a phone upload a portrait image, drag and resize crop selection, watch Left/Top/Width/Height update. Edit numbers, verify box and output.
2. Add Image Watermark: drag text, enlarge using corner, verify numeric size changes, export actual output.
3. Compress: try already-compressed JPEG, PNG with transparency, and high-detail photo. Never offer a file larger than original; note changes to quality/dimensions.
4. Background Remover: try portrait with hair, a product with a complex background, transparent result and a new color. Confirm first model download, no image upload, realistic cutout and limits. If it fails, do not consider the tool production-ready.
5. PDF Organizer: upload 3+ real pages, confirm readable thumbnail previews, reorder by touch-friendly arrow, export and verify actual PDF page sequence.
6. PDF Watermark: drag watermark and resize, select specific pages vs all pages, export and verify with multiple pages.
7. PDF Crop: drag crop rectangle, edit margin numbers, inspect resulting PDF; remind users that hidden content is not deleted.
8. PDF to Images: load real multi-page PDF, verify distinct previews and independent PNGs; ZIP contains all pages.
9. Image OCR: upload Malay and English text screenshots, Copy, Download TXT, inspect errors.
10. File Converter: run PDF to text-based DOCX, PDF to XLSX, image to PDF, and print-to-PDF modes, inspect previews and actual files.
11. Text Counter: verify live count in mobile browser.
12. In every family verify Zrain UI, Zrain Community, input-first layout, mobile no horizontal scrolling, disabled/error states, and all downloads open.

**Do not sign off based only on successful HTTP 200 responses or automated static tests.**
